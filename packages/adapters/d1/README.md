# @kalayaan/adapter-d1

Cloudflare D1 storage adapter for [Kalayaan](https://github.com/periabyte/kalayaan-cms) — implements
the `@kalayaan/core` storage contract on top of D1, built on the shared SQL query builder in
`@kalayaan/adapter-relational`.

Selected automatically by the `kalayaan` CLI when a project targets Cloudflare's default D1 storage;
not typically installed directly.
