# @kalayaan/adapter-relational

Shared SQL query builder and adapter base used by [Kalayaan](https://github.com/periabyte/kalayaan-cms)'s
relational storage adapters (`@kalayaan/adapter-d1`, `@kalayaan/adapter-postgres`,
`@kalayaan/adapter-mysql`) — collection CRUD, filtering, and migration DDL generation shared across
SQL dialects.

An internal building block for adapter authors, not meant to be used directly by CMS end users.
