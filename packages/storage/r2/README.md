# @kalayaan/storage-r2

Cloudflare R2 media storage adapter for [Kalayaan](https://github.com/periabyte/kalayaan-cms) —
implements the `@kalayaan/core` media storage contract for uploads, the media library, and asset
serving.

Selected automatically by the `kalayaan` CLI when a project targets Cloudflare's default R2 storage;
not typically installed directly.
