# @kalayaan/admin

The schema-driven React/Tailwind admin SPA served by a deployed
[Kalayaan](https://github.com/periabyte/kalayaan-cms) site (command palette, TipTap rich-text
editor, media library, publish workflow, roles/permissions UI).

The `kalayaan` CLI bundles this at build time and uploads it alongside the Worker on
`kalayaan deploy` — it isn't meant to be installed or run standalone.

See [`CLAUDE.md`](https://github.com/periabyte/kalayaan-cms/blob/main/CLAUDE.md#admin-ui-conventions-packagesadmin)
for the admin UI's design system and conventions.
