# Security Policy

## Supported Versions

Kalayaan is pre-1.0 and moves quickly. Only the latest published release is supported with
security fixes.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < latest| :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities privately via
[GitHub Security Advisories](https://github.com/periabyte/kalayaan-cms/security/advisories/new)
rather than filing a public issue.

Include what you can: affected package/version, reproduction steps, and impact. You should get
an initial response within a few days. If accepted, a fix will be released and the advisory
published with credit (unless you'd prefer to stay anonymous); if declined, we'll explain why.
